Política de Privacidade — Gmail Claude

Última atualização: 15/10/2026.

Quem somos

O Gmail Claude é um aplicativo de uso pessoal de Gleidson Benfica Fernandes. Ele só acessa as contas Gmail que o próprio dono autoriza.

Dados acessados

Com a autorização do dono, o app acessa o conteúdo e os metadados dos e-mails, rótulos e rascunhos das contas autorizadas, para ler, buscar, organizar, enviar e responder mensagens a pedido do dono.

Como os dados são tratados

  • O app roda localmente no computador do dono. Não existe servidor do app que receba ou armazene e-mails.
  • Os tokens de acesso ficam em um arquivo local protegido, legível apenas pelo dono.
  • O conteúdo dos e-mails é enviado apenas ao assistente Claude (Anthropic) quando o dono pede uma tarefa, para que ela seja executada.
  • Os dados não são vendidos, compartilhados com terceiros para publicidade nem usados para treinar modelos pelo desenvolvedor do app.

Uso de dados de APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar o acesso e excluir dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao remover uma conta do app, os tokens dela são apagados do computador.
